文档导演台 · 详细使用说明
============================================================
版本：2026-11   适用：Windows + 本机运行的 ComfyUI
（工具本身与具体模型无关，换工作流照常使用）


============================================================
第一章  它是干什么的
============================================================
输入：
    · 一份分段提示词 .md（每段一段提示词 + 该用哪几张图）
    · 一个参考图文件夹
输出：
    · 每段一个 mp4，最后拼成一整集

它不是生成模型，而是「导演助理」：

    分段文档 + 素材图
          │
          ▼
    解析：切段、抓提示词、按名字匹配图
          │
          ▼
    逐段提交本机 ComfyUI（把图拷进它的 input 目录）
          │
          ▼
    回收产物、记录状态与版本
          │
          ▼
    ffmpeg 统一规格 + 拼接 → 整集成片 → 导出

画面质量、风格、镜头语言由 ComfyUI 那边的工作流和模型决定，
本工具只负责「按流程、按顺序、不出错地跑完」。


============================================================
第二章  电脑上要先有什么
============================================================
1. Python 3.9 以上（安装时勾选 Add Python to PATH）
   验证：cmd 里输入  python --version  能看到版本号
   （Windows 上装 ComfyUI 整合包的，包里自带的 python_embeded 也能用，
     启动脚本会自动去找）

2. ffmpeg（合成整片才用到），两种方式任选：
   A. 免安装（推荐）
      把 ffmpeg.exe 和 ffprobe.exe 复制到本工具目录
      （和 doc_director.py 放一起），程序会优先用同目录下的这两个文件
   B. 装进系统
      安装后把 bin 目录加进系统环境变量 PATH，cmd 里 ffmpeg -version 有输出即可

3. ComfyUI 在运行，浏览器能打开 http://127.0.0.1:8188

4. ComfyUI 里装着本工作流需要的模型和自定义节点
   · 具体哪些模型：打开随包的 comfyui_latest.json，
     里面 UNETLoader / CLIPLoader / VAELoader / LoraLoaderModelOnly
     节点的 *_name 字段就是文件名，必须和 ComfyUI 里的一致
   · 缺少自定义节点时，ComfyUI 画布里会显示红色节点；
     按节点名在 ComfyUI-Manager 里补齐即可
   · 换过模型就没法照搬：见第十二章


============================================================
第三章  启动与首次配置
============================================================
1. 先启动 ComfyUI，等它输出 Running on 127.0.0.1:8188
2. 双击「启动文档导演台.bat」
   脚本会自动找 Python：系统 PATH → py 启动器 → ComfyUI 整合包的 python_embeded
   找不到会弹中文提示，不会一闪而过
3. 浏览器自动打开 http://127.0.0.1:8771

首次要配的路径，都在顶部「▸ 数据源与 ComfyUI 设置」里：

   提示词       分段提示词 .md 文件              [选择文件…]
   素材图       参考图文件夹                     [选择文件夹…]
   输出目录     ComfyUI 的 output 文件夹          [选…]
    ComfyUI 地址 默认 http://127.0.0.1:8188

为什么只要这三项：
   程序会从「输出目录」的上一级反推 ComfyUI 根目录，
   再用它推导出另外两处必需位置
       <根>\input\doc_director          参考图复制到这里，节点才读得到
       <根>\user\default\workflows     「同步节点名」从这里读你保存的工作流
       <根>\models\                     启动自检核对模型是否齐全

   所以「输出目录」要选对层：
       C://...//ComfyUI//output        ← 选这一层
       它旁边应该有 input、models、user 三个文件夹

三个输入框都能直接粘贴路径，并记住最近 12 条历史，点进去就列出来。

配好后底部日志：
   自检通过：ffmpeg · 输出目录 · 模型 · 文档 · 素材库
缺项会写「⚠ …」并告诉你点哪个按钮。

第四章  文档怎么写（解析规则）
============================================================
段标题是唯一的分段依据，必须是这一行：

    ### G01 · 00:00-00:12（12 秒）｜本段标题

规则：
· 必须以三个井号 ### 开头（#### 或 ## 都不认）
· 段号是 G + 数字（G01、G02…）
· 时间码 分:秒-分:秒，秒必须两位（00:12 可以，0:12 不行）
· 时长必须写成（12 秒），单位只能是「秒」，12s / 12sec 都不认
· 「·」和「｜」可有可无，竖线后面整段当标题

段内三块内容：

1）图槽
    **上传图**：图1 `角色A.png`｜图2 `场景B.png`｜视频1 `动作参考.mp4`
    · 关键词是「上传图」或「上传素材」，后面必须跟中文冒号 ：
      用半角冒号会导致图槽全空，这段会被自动标成「跳过」
    · 槽之间用 ｜ 或 | 分隔；图槽 1-9，视频槽 1-5
    · 文件名优先取反引号里的；没有反引号就取「图N」后面的文字、截到第一个括号前
    · 写 无图 / 无 / — / - 表示该槽留空
    · 每段只认第一行带「上传图」的

2）英文提示词（真正发给模型的）
    **【英文版】**

    （三个反引号的代码块，里面是提示词正文）

    · 没有【英文版】标记或代码块 → 提示词为空 → 生成必然失败

3）中文版（只做对照，不发送）
    **【中文版】** + 代码块

可选：段总表（「上传图」行缺失时当图槽兜底，平时可不写）
    | 段号 | 时间码 | 时长 | 镜号 | 内容 | 图1 | 图2 | 图3 |
    | G01 | 00:00-00:12 | 12 | 3 | 本段标题 | 角色A.png | 场景B.png | 空镜C.png |
    必须 8 列、以 | 开头。

文件编码用 UTF-8（带 BOM 也行）。

常见格式错误对照：
    解析出 0 段            标题格式不对，多半是秒写了 1 位，或写了 12s
    某段莫名被跳过         图槽全空，常见于「上传图」用了半角冒号
    后面所有段都没了       段内出现了 ## 两级标题，它会掐断当前段

第五章  素材图与匹配规则
============================================================
匹配是「同名才算」，不做模糊匹配：

    文档写 角色A.png，库里有 角色A.png            → 成功
    文档写 角色A（没写扩展名），库里有 角色A.png   → 成功（自动补 .png）
    文档写 角色A.jpg，库里有 角色A.png            → 成功（主名一致，扩展名不同）
    文档写 角色A.png，库里有 角色A侧脸.png         → 失败
    文档写 角色，库里有 角色A.png                  → 失败

没匹配上的图槽会标红 ⚠，可以在下拉里手动选。
下拉点开就是搜索框，输入即过滤：
    前 3 项按相似度排，第 4 项起按使用频次排

「素材库 N」打开素材面板：缩略图、被几段引用、改名、上传、
删除（进素材回收站，可还原）。

第六章  界面地图
============================================================
顶部第一行分三段：
  左：标题 + ComfyUI 状态 + 生成全部 / 只跑未完成 / 停止 / 合成整片 / 导出视频
  中：重新解析文档 / 重新匹配素材 / 导出修改稿 / 删除上传文档
  右：已删除 N 段 / 素材库 N / 折叠图槽 / 工作流映射 / 备份恢复 / 配色

  折叠条「▸ 数据源与 ComfyUI 设置」右侧有 ⛶ 全屏

统计行：
  共 N 段 · 需生成 N · 已完成 N · 总时长 Ns · 素材库 N 张
  右侧「清除筛选」「筛选 ▾」「展开提示词」「折叠提示词」

  · 展开提示词：把当前显示出来的段全部展开
    有筛选时只展开筛出来的那几段；清掉筛选后，已展开的仍保持展开
  · 折叠提示词：一次性全部收起

表格列：
  # | 段号 | 内容/提示词 | 时长s | 图1/图2/图3 | 状态 | 操作

每行操作：生成 / 跳过 / 看片 / 删除
段号右边有 ✎，可以改段号（只能改还没生成过视频的段）

表格最下方有「＋ 新增一段」：
    · 段号自己填，字母 + 数字，比如 G23、A01
    · 时长默认 8 秒，可改
    · 时间码自动接着上一段的结尾往后排
    · 标题会同步到「导出视频」列表（成片显示的就是这个标题）
    · 创建后自动展开，直接填提示词、选图槽就行
    · 段号默认 = 当前「没被删除」的段里最大的那个 +1
      （删过段也按剩下的算：最新是 G14，新段就是 G15）
    · 勾「不用参考图」→ 纯文本生成：提交时把所有参考图连线摘掉、
      LoadImage 节点一并删除。能不能真的出片取决于你的工作流节点
      是否支持空参考图，失败会显示 ComfyUI 的真实报错
展开「看/改提示词」后可以：
    · 选「正面提示词：英文版 / 中文版」
    · 直接改提示词（自动保存，重新解析也不会被覆盖）
    · 按内容自适应 / 重置高度
    · 若映射里配了附加文本槽，还会多出勾选框 + 输入框

第七章  筛选与批量操作
============================================================
点「筛选 ▾」展开筛选栏（三个多选下拉 + 全文搜索）：

  #        序号
  段号      G01、G02（换文档后自动跟着变）
  状态      待生成 / 生成中 / 已完成 / 失败 / 已跳过
  搜索框    同时搜 段号 + 标题 + 英文提示词 + 中文提示词

三个下拉互相联动：选了 G04，序号那边就只剩 4。
每个下拉里能直接打字批量选：
    序号  1,5,6
    段号  G01,G02（只写 1,2 也认）
    状态  失败,完成（中英文都认）
回车生效，分隔符 , ， 、 空格 都行；标题右侧的 × 一键清空该筛选。

重要：筛选会影响「生成全部」的范围 —— 筛出 3 段再点，只跑这 3 段。

第八章  生成、状态与版本号
============================================================
状态：待生成 / 生成中 / 已完成 / 失败 / 已跳过
失败的行会显示红字摘要，点开是完整报错。

同一段重复生成自动加版本号：
    G01-1（新）.mp4     第 1 次
    G01-2（新）.mp4     第 2 次（G01-1 自动去掉「（新）」）
    G01-3（新）.mp4     第 3 次
· 只有最新那版带（新）
· 旧版本都留在输出目录，不覆盖
· 导出时文件名去掉（新），版本号保留

第九章  合成整片
============================================================
点「合成整片」会弹出一个选择面板：
· 列出所有段落，带视频缩略图、段号、标题、时长、状态、有没有成片
· 缩略图点一下就弹全屏播放这一段（点空白处或按 Esc 关闭）；
  还没生成的段显示虚线空框，合成时自动补黑场
· 列表正上方三个筛选（序号 / 段号 / 状态）+ 搜索，和主表格完全一样的多选规则，
  也能直接输入 1,5,6 或 G01,G02 回车批量选
· 勾选要合进去的段，按表格顺序拼接
· 全选（当前筛选）/ 全不选 / 反选
· 没生成的段自动补黑场，不会断
· 统一分辨率、帧率、音轨格式

全部勾选时输出 成片_全片.mp4；只勾一部分时输出 成片_自选.mp4。

注意：合成以「第一段有输出的分辨率」作为全片统一尺寸。
如果前面的段是低分辨率旧片，后面新生成的高清段会被压回去。
换过分辨率后要重跑旧段，或先清掉旧输出。

第十章  导出视频与回收站
============================================================
「导出视频」面板按 段号 → 版本号 列出所有成片。
列表上方有三个筛选 + 搜索，规则和主表格一致：
   段号    勾选要看的段（可输入 G01,G02 回车批量选）
   版本    最新版 / 旧版
   时间    今天 / 近 3 天 / 近 7 天 / 更早
   搜索    文件名、标题都能搜
每个下拉都有「清空 · 显示全部」，标题右侧有 ×；三个条件叠加生效。

· 每行：缩略图（点一下播放）、文件名、标题、时长、大小、删除
· 最新那版后面有蓝色「新」标记
· 顶部：开始导出 / 回收站 / 另存为… / 全选

  开始导出   勾选的文件复制到你指定文件夹（去（新）标记）
  另存为…    只勾 1 个时可用，弹系统保存框
  删除       移到回收站，不销毁源文件；该段状态回到「待生成」

回收站：
· 列出被删成片，可「还原」
· 只有「彻底删除」才真的从硬盘删除
· 文件在工具目录下的 _video_trash

第十一章  数据安全三件套
============================================================
1. 导出修改稿
   把当前分段导出成 .md 或 .txt：
   · 界面里改过的提示词、图槽、中英文选择都会写进去
   · 已删除的段不会写进去
   · .md 纯 UTF-8；.txt 带 BOM，记事本打开不乱码
   · 两种都能再导回导演台

2. 删除上传文档
   清空当前文档解析出的所有分段（文件本身不删）：
   · 清空前自动备份到 _bak\shots.cleared-时间.json
   · 已生成的视频留在输出目录，不受影响
   · 素材库、工作流映射、配色等设置全部保留

3. 备份恢复
   列出 _bak 里所有快照（时间、段数、大小），可一键恢复：
   · 恢复前先把当前数据另存为 shots.before_restore-时间.json
   · 所以恢复本身也能反悔

删段是软删除：只是不参与生成和合成，顶部「已删除 N 段」可恢复。


============================================================
第十二章  工作流映射与换模型
============================================================
这是这套工具唯一需要「对接」的地方。

点「工作流映射」可以看到：
· 正面提示词节点：每段的提示词写到哪个文本框（通常是 PrimitiveStringMultiline）
· 图槽节点：每张参考图接到哪个 LoadImage
· 输出节点：成品从哪个 VHS_VideoCombine 出来
· 时长 / 种子 / 提示词这些值写进哪个节点
· 附加文本槽：工作流里还有别的文本框（比如触发词、主体定义），
  可以加进来，每段单独决定要不要注入

三种情况：
A. 用随包的工作流，模型也一样
   什么都不用改，直接跑

B. 模型名字不一样（最常见）
   ComfyUI 里调通 → 菜单「导出 (API)」→ 导演台「工作流映射」上传 → 保存
   启动自检会核对模板里写死的模型名，对不上会直接提示

C. 整套工作流都不一样
   同上。图槽数量会跟着工作流变（有几个 LoadImage 就出几个槽），
   认不准的位置在面板里手动指一下

换模型、换工作流都不会丢分段数据：提示词、语言、附加文本、
生成状态、版本号全在 shots.json 里。

第十五章  设置（右上角「设置」）
============================================================
1. 失败自动重试
   0-5 次，间隔 2 秒。显存抖动导致的偶发失败，重试一次常常就过了。
   连续用尽次数才算失败（失败后会停下整个队列，和以前一样）。

2. 自动隐藏（只是不显示，文件不删）
   超过 N 天（1-30）没改动过的素材 / 成片，点「立即执行」后从列表里隐藏：
   · 素材：不再出现在素材库和下拉里
   · 成片：不再出现在导出面板里
   · 文件仍在原处，随时点「全部恢复显示」回来
   · 还被某一段引用着的成片不会被隐藏
   隐藏清单存在 hidden.json。

3. 提示词片段
   在这存常用片段（运镜、负面词、画风描述…），名称 + 文本各一条。
   展开某段后，提示词上方的「插入片段」下拉可以直接追加到末尾。

4. 日志
   · 下载本次日志 / 下载上一次日志（每次启动都会把上次的存成 .1）
   · 查看完整日志：页面上只显示最近 500 行，这里能看全文
   日志同时写在工具目录的 doc_director.log。

第十六章  生成时的一些约定
============================================================
· 生成过程中改提示词也算数：每段开始前会重新读一次数据，
  所以第 5 段在跑的时候你改第 8 段，第 8 段用的就是新内容
· 批量生成前会本地预检：正面提示词为空、时长不是正数、图1 没选
  （又没勾「不用参考图」）的段，直接标红跳过，不去浪费显卡
· 单段点「生成」不受预检限制，想硬跑就硬跑
· 标题可以直接改（标题右边的 ✎），导出面板显示的标题就是它


============================================================
第十七章  显存与画质
============================================================
显存不够（报 OutOfMemory）时按这个顺序降级，别反着来：
    ① 少填参考图（4/5/6 槽不必都填）
    ② 工作流映射里把参考图「最长边」调小
    ③ 最后才降 megapixels / 分辨率

画质不够时反过来：
    ① 提 megapixels（分辨率）
    ② 参考图最长边调大
