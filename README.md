# 文档导演台 · 方块纪元

丢一份 **分段提示词 Markdown** + **一个素材图文件夹**，自动跑完一集：解析文档 → 匹配素材 → 灌进 ComfyUI → 逐段生成 → 合成整片。

比旧「导演台」多做的三件事：

1. **不用手填分镜表**：直接读 `方块纪元-第01集-分段生成提示词-5到20秒版.md` 这种格式的文档。
2. **素材自动匹配**：文档里写「图1 林野（男主）.png」，就自动去素材库找；找不到会用模糊匹配兜底。
3. **图片自动转安全名**：中文文件名复制成 `asset_xxxx.png` 放进 ComfyUI input，避免中文路径读不到。

---

## 启动

双击 **`启动文档导演台.bat`**，浏览器自动打开 `http://127.0.0.1:8771`。
（旧导演台在 8770，两个可以同时开，互不干扰。）

前置条件：
- ComfyUI 已在 `127.0.0.1:8188` 运行
- 系统装了 `ffmpeg` / `ffprobe`（合成要用）
- `workflow_api_template.json` 放在本目录（已带）

## 换到另一台电脑

不是拷过去就能跑，先确认四样：

| 依赖 | 要求 | 怎么查 |
|---|---|---|
| Python | 3.9+，且在 PATH 里 | cmd 敲 `python --version` |
| ffmpeg / ffprobe | 在 PATH 里 | `ffmpeg -version` 有输出 |
| ComfyUI | 本机 `127.0.0.1:8188` 跑着 | 浏览器打开能进界面 |
| ComfyUI 的模型 / 自定义节点 | 和这份工作流一致 | 见下 |

这套工作流用到的（少一个都会报错）：

- unet `DasiwaMinimaxH3_…_int8`、clip `qwen3vl_32b_minimax_h3_…`、vae `minimax_h3_video_vae_fp16` / `minimax_h3_audio_vae_fp32`、lora `minimax_h3_fl2v_turbo_4step_v1.2_768p`
- 自定义节点：MiniMax H3 系列、BlockSparseAttention、MiniMaxLowVRAMAttention、VHS_VideoCombine、rgthree、KJNodes、easy-use；（RelayVSR 超分可选）

**最省事的迁移方式**：把整个 ComfyUI 目录（含 `models/`、`custom_nodes/`）一起拷，比在新机器一个个重装快得多。

启动后只要改顶部三个路径（都有「选择文件夹…」按钮，不用手改 json）：

1. **文档** → 分段提示词 `.md`
2. **素材库** → 图片文件夹
3. **输出目录** → 新机器 ComfyUI 的 `output` 目录（这个最容易漏）

改完点「重新解析文档」。

> `config.json` / `shots.json` / `workflow_map.json` / `node_titles.json` 都是状态文件，可以一起拷。
> 里面的绝对路径到了新机器会失效，但上面三个框改一下就行，不需要手动编辑。

## 两种用法

### A. 直接用本地文件（最快，零拷贝）
顶部两行是路径：

- **文档**：你的分段提示词 `.md`。点右边 **「选择文件…」** 会弹系统文件框（只列 `.md`），选完自动重新解析
- **素材库**：图片文件夹，比如 `...\穿越我的世界\第一集\资产图`。点 **「选择文件夹…」**，选完自动重新匹配素材

两个输入框都能直接粘贴路径，而且**记住最近用过的路径**——点进输入框就能从下拉历史里挑。

> 对话框优先走 tkinter（python.org 装的 python 都自带）；如果那个 python 是精简版、没带 tkinter，
> 会自动改用 Windows 自带的 PowerShell + WinForms。两条都不通时，路径直接粘进输入框照样能用。

### B. 想把文件随工具一起带走

直接把 `.md` 和素材图文件夹拷到工具目录旁边，再用上面 A 的方式选路径就行。

> 旧版的「上传到 `_docs/` / `_assets/`」入口已经去掉了 —— 它会把文件复制一份，
> 容易和原文件不一致，而且和 A 的选路径功能重复。

## 文档要长什么样

工具认这个结构（你现有的文档完全符合）：

```markdown
| 段号 | 时间码 | 时长 | 镜号 | 内容 | 图1 | 图2 | 图3 |     ← 段总表（兜底用）

### G01 · 00:00-00:12（12 秒）｜日常蒙太奇 3 镜      ← 段标题：段号 + 时间 + 时长 + 内容

**上传图**：图1 `林野（男主）.png`（人物：林野）｜图2 `地铁车厢.png` ✅已有（场景）

**【英文版】**

```text
（这一段就是发给模型的提示词）
```

**【中文版】**

```text
（只做对照，不发送）
```
```

解析规则：
- **段标题识别很宽松**：段号（G数字）、时间码、时长的**顺序和写法随意**，下面这些都能认——

  ```markdown
  ### G01 · 00:00-00:12（12 秒）｜日常蒙太奇     ← 标准写法
  ### G01 00:00-00:12 (12s) 日常蒙太奇           ← 半角括号、s 单位
  ### G1 · 12秒 · 日常蒙太奇                     ← 没时间码，按前面段累出来
  #### 00:00-00:12 · G01 · 日常蒙太奇            <!-- 乱序、换标题级别 -->
  G04 00:30-00:38（8秒）开场                     <!-- 不写 # 也行 -->
  **G05 12秒 黑场过渡**                          <!-- 加粗行 -->
  ```

  时间分隔符 `-` `–` `~` `到` `至` 都认；时长可以是 `12秒` / `12s` / `时长12`。
  判定条件：一行里有 G 段号，并且（有时间码或有秒数）。正文里随口提到「G02」不会误判。

**通用提示词文档也能用**：如果整份文档一个 G 段标题都没有，会自动按
**空行 / 序号（`1.` `2、` `一、`）/ `---` 分隔线 / 标题行** 切成一段一段，
段号自动编 G01、G02…，每段默认 8 秒。整段正文就是提示词（不用写【英文版】标记）。
没有匹配到素材的段**不会自动跳过**——图1 在界面手动选一张，或者标成跳过。
只想改每段秒数：界面上直接改即可。

**「第N段」板式也认**（H3 六字段提示词常见写法）：

```markdown
### 第1段｜穿越醒来｜16秒｜H3 Ref2VA

| 槽位 | 文件名 | 职责 | 适用Shot |
|---|---|---|---|
| Picture 1 | lin_identity.png | 人物身份参考 | Shot 1-6 |
| Picture 2 | mc_night_forest.png | 场景参考 | Shot 1-6 |

```text
subject_definitions: ...
```
```

- 段标题认 `### 第N段｜标题｜秒数`（`第 1 段` 带空格也行），自动映射成 G01、G02…
- **上传顺序表**：`| Picture N | 文件名 | ...` / `| 图N | 文件名 | ...` / `| Video N | ...`
  都会读进对应图槽/视频槽（和「上传图」行二选一或混用）
- **提示词不用写标记**：正文里有代码块（```text …```）就取第一个代码块；
  没有代码块就用整段正文。**只写了【中文版】没写【英文版】时自动按中文喂**，
  不会发出空提示词
- 图槽取「上传图」行反引号里的文件名；没有反引号就取括号前文字；**该行缺失时回落到段总表**
- 「无（不需要参考图）」这种 → 三槽全空 → 自动标记**跳过**（纯黑/字幕段）
- 【英文版】/【中文版】两块的代码块都会被解析，**发哪块由每段的下拉决定**（默认英文）

## 素材匹配顺序

只认「名字一致」，不做模糊匹配（免得拿错图）：

1. 文件名完全一致
2. 补 `.png` 后一致
3. 去扩展名后一致（`草原.jpg` ↔ `草原.png`）
4. **去掉括号补充说明后主名一致**：
   文档写 `周桂兰人物设定图（正面全身 + 面部特写）` → 括号段不参与匹配，
   按 `周桂兰人物设定图` 对上库里的 `周桂兰人物设定图（正面全身+面部特写.png`。
   表格里的「图片内容」列（中文名）就是这么识别的；主名太短（<4 字）不做这级，免得误伤

匹配不上会标红 ⚠，可以直接在下拉框里手动选（手选会记住，重新解析不丢）。
**重新匹配素材** 按钮会在你换了素材库后重跑一遍（不覆盖你手选的结果）。

## 界面操作

| 按钮 | 作用 |
|---|---|
| 重新解析文档 | 文档改了之后重新读（保留状态/已改的提示词） |
| 重新匹配素材 | 素材库加图后重新对一遍名字 |
| 生成全部 | 从第一段跑到底（跳过标记为「跳过」的段） |
| 删除上传文档 | 清空当前文档解析出的所有分段（文件本身不删），清空前自动备份 `shots.json` 到 `_bak/` |
| 导出修改稿 | 把当前分段导出成 `.md` 或 `.txt`（内容一致，`.txt` 带 BOM 记事本直接看），改过的提示词/图槽/中英文选择都在里面 |
| 备份恢复 | 列出 `_bak/` 里的所有 `shots.json` 快照，可一键恢复（恢复前也会先备份当前数据） |
| 只跑未完成 | 断点续跑，已完成的不重跑 |
| 停止 | 当前段跑完后停下 |
| 合成整片 | ffmpeg 归一化 + 拼接，未生成的段自动补黑场 |
| 导出视频 | 挑某几段或全部，复制到你指定的文件夹 |
| 另存为… | 在导出面板里，把**当前勾选的那一段**用系统「另存为」框存成单个文件（一次一个，文件名默认 `G01.mp4`） |
| 已删除 N 段 | 查看被删的段，可单条或全部恢复 |
| 素材库 N | 打开素材面板，看缩略图、被几段引用、删除单张图 |

每段还能单独「生成」、单独「跳过/启用」、展开改英文提示词和时长。

### 提示词框与图槽

- **拖动高度**：提示词框右下角可以拖着改高度，**每段各自记住**（存在浏览器本地），收起再展开、切到别的段再回来，高度都还是你拖的那个尺寸
- **按内容自适应**：按文本实际长度一次撑开
- **重置高度**：回到默认高度
- **图槽缩略图**：图1/图2/图3 每行左边都有当前素材的小缩略图，**点一下在当前页放大**（再点任意处或按 Esc 关闭），空槽是虚线框
- **表头置顶**：表头会跟着顶部工具栏的真实高度固定在下面，往下滚动时一直可见，不会压住数据
- **弹窗**：点旁边的空白处就能关，不用专门去找关闭按钮；Esc 也能关
- **看片**：点「看片」**直接在浏览器里播放**（弹层带进度条，可以拖），不跳页、不弹文件路径
- **导出预览**：导出列表每行左边有视频缩略图，**点一下就地播放**，勾选不受影响
- **节点搜索**：工作流映射里的下拉框**本身就能打字**——点它，直接输「图」「种子」「seed」「#270」就筛出来了，选中回车即可
- **图槽按需显示**：文档里某段写了几张图，表格就显示几行（写图1/图2 就两行，写到图3 就三行）。行下面有 **「+ 图槽」** 可以手动加一槽，加了之后有 **「− 图槽」** 可以退回去
- **折叠图槽**：顶部「折叠图槽」按钮，一键让所有段只显示第一张，列表变清爽；再点一次展开
- **中英切换**：展开某段，第一行有个下拉，可以选「英文版 / 中文版」——选哪个就把文档里对应的那版喂给模型，另一版只做对照。**每段独立记**，默认英文；重新解析文档后也不会丢（改过哪版就保留哪版）
- **附加文本槽**：工作流映射面板里有「附加文本槽」，是一个**可打字搜索的下拉框**（节点名 / 类名 / #编号 都能搜），列出模板里所有能输入文本的节点；选中一个就加一个槽，每段随即多出一组输入框 + 勾选框。**勾上才注入**这段写的内容，不勾保持模板原值。默认一个都不加，主提示词节点也不会重复列。

## 生成进度

顶部「ComfyUI 在线」后面出现 **「进度已连」** 时，说明已经接上 ComfyUI 的 WebSocket：

- 正在生成时会显示 `正在生成：G01 · 节点 5386 · 12/20 · 87s`
- 节点名就是当前跑到哪一步，数字是这一段的采样步数进度，最后是已用时间
- ComfyUI 队列里还有别的任务时，会提示「还排着 N 个」

> **为什么在 ComfyUI 画布上看不到绿框？** 因为导演台是通过 API 提交任务的，
> ComfyUI 只把任务放进队列（左边「队列」面板能看到），**不会在画布上执行、不会高亮节点**——
> 这是 ComfyUI 本身的机制，界面里手动点「运行」才会在画布上有绿框。所以进度看这边就行。

## 删除键（两类，都不会真销毁东西）

### 1. 删掉某一段
表格每行最右边 **「删除」** → 这段从列表消失，**不参与生成、也不进成片**（时间轴直接少这一段，不是补黑场）。

- 是**软删除**：只是打标记，数据还在
- 顶部 **「已删除 N 段」** 里能看到全部被删的段，**单条恢复**或**全部恢复**
- 改文档后重新解析，被删的段仍然是删除状态（不会自己回来）

### 2. 删掉单张素材
点顶部 **「素材库 N」** → 缩略图网格，每张下面写着**「用 N 段」**，点「删除」：

- 有段在用它会先告诉你「有 N 段正在用它」，确认后这些段的图槽会被**清空**（之后会标红 ⚠）
- 文件**不会销毁**，而是移进本工具目录的 **`_trash`** 回收站
- 素材面板里点 **「回收站」** 可以看、可以**还原**（还原回原文件名）

> 这一条是刻意做的：素材库在你自己的资产目录里，直接销毁风险太大，所以统一走回收站，删错了随时捞回来。

删完素材可以点 **「重新匹配素材」** 让它重新找别的图，或在下拉框里手动选。

### 3. 上传素材 / 改名

素材面板里：

- **「上传图片」**：可以一次多选，直接传进**当前素材库目录**（不是单独缓存目录），传完自动重新匹配
- **「改名」**：改完文件名后，**所有引用这张图的段落会自动同步**，不用手动重选
- **点缩略图**：在新窗口看大图

> 改名只动文件名，不动图片内容。如果新名字和已有文件重名，会拒绝并要求换个名字。

## 换工作流怎么办（通用支持）

**任何「文字 + 图 → 视频」的 ComfyUI 工作流都能用**，节点 ID 不用改代码。

启动时会自动读工作流，认出五个槽位：

| 槽位 | 识别规则 |
|---|---|
| 提示词 | `PrimitiveString*` 节点（优先 Multiline、优先当前已有内容的）；退而找 `CLIPTextEncode` 的 `text` |
| 时长 | input 名含 `length/duration/seconds/frames/num_frames…`，或 Primitive 数值节点。Primitive 的 `length` 当秒，其他节点（Wan/CogVideo/AnimateDiff）的 `length` 当帧 |
| 种子 | input 名 `seed/noise_seed`，优先专门的 Seed 节点，采样器自带的靠后 |
| 图槽 | `LoadImage` 节点；顺序优先跟着 `ref_image_0/1/2`、`image1/image2` 这类带序号输入的连线走，找不到再按节点 ID 排 |
| 输出 | 有 `filename_prefix` 的节点（多个就都填，第 2 个起自动加 `_2` 后缀） |

识别结果存进 `workflow_map.json`，模板一换就重新识别。

### 节点名怎么来的

下拉框里显示的是 **ComfyUI 里节点顶部的名字**，不是节点 ID 和类型。三个来源，优先级从高到低：
1. **你导入的名字**（点「导入节点名」上传 ComfyUI 里 Ctrl+S 保存的 `.json`，界面格式就行）
2. 工作流自带的 `_meta.title`
3. 自动起的规范名：图槽按顺序叫「图1/图2/图3」，种子节点叫「种子」，时长节点叫「视频时长」

所以通常你什么都不用做，打开就能看到「图1 · #264」「种子 · #5417」这样的选项。
只有在 ComfyUI 里改过名字、想完全对齐时，才需要导入一次。

**从 ComfyUI 实时同步**：点 **「从 ComfyUI 同步节点名」**，工具会去扫
`ComfyUI/user/default/workflows/` 下所有 `.json`，挑节点 ID 和当前模板对得最多的那份，
把里面的节点名字拿过来并重新识别一遍。所以你在 ComfyUI 里改完节点名 **Ctrl+S 保存**一下，
这边点一下按钮就同步了；打开「工作流映射」面板时也会自动检查一次，有变化会自动提示。

> 注意：ComfyUI 只把**手动改过名字**的节点写进 `title` 字段。没改过名的节点读出来是空的，
> 这时会退回用自动规范名（图1/图2/图3/种子）。

### 改了名但这边没变？看这里

ComfyUI 的节点名只存在**浏览器内存**里，不保存不运行的话，磁盘上根本没有任何文件记录它，
任何外部工具都读不到（不是这个工具的问题）。

三种让它生效的方式，任选：

| 方式 | 操作 | 生效时间 |
|---|---|---|
| **保存工作流**（推荐） | ComfyUI 里按 `Ctrl+S` | 这边 **5 秒内自动同步**，不用点按钮 |
| **跑一次** | 点一下「运行」，跑起来就行 | 打开「工作流映射」面板时自动同步 |
| **直接在导台里改名** | 点开下拉框，**第一行「✎ 给 #xxx 起个名字…」** | 立即生效，且**锁定**，不会被 ComfyUI 的旧名字覆盖 |

第三种最适合图省事的情况。清空名字就恢复默认。手动起过名的节点会记在 `title_locks.json` 里，
以后 ComfyUI 再同步也不会把它冲掉。

识别时也会参考这些名字：「图3」会被认成第 3 个图槽、「种子」会被认成种子节点、「视频时长」会被认成时长节点，比纯按节点 ID 猜准得多。

### 一键从 ComfyUI 导入完整工作流（推荐）

不用手动导出，最快的方式：

1. 在 **ComfyUI 里点一次「运行」**（跑起来就行，不用等跑完；不想真跑就点完立刻取消）
2. 到导演台点 **「工作流映射」→「从 ComfyUI 导入」**
3. 面板会立刻出现工作流里**全部**的图槽（图1…图9）、视频槽、输出节点，节点名也是你在界面上起的

原理：ComfyUI 每次提交都会把完整的 API 工作流存进自己的队列/历史，导台直接从那里取最完整的那一份，所以拿到的一定和你画布上的一致。

> 如果提示「比当前模板还少」，说明你还没在 ComfyUI 里跑过那份完整工作流，先点一次运行再来。

### 图槽 / 视频槽：有几个就出几行

工作流里有几个 `LoadImage`，面板里就出几个图槽（图1、图2、图3……图9），**不再固定三个**。

同样，工作流里有参考视频节点（`VHS_LoadVideo`、`LoadVideo`、`LoadVideoUpload` 等），就会多出「视频槽」区域（视频1、视频2…）。

想让槽位跟着 ComfyUI 变，**要重新导出一次 API 工作流**：
ComfyUI 里加完节点 → 菜单 **「导出 (API)」** → 在面板点「上传工作流 / 导入节点名」传上来。
节点名可以另外用界面保存的 `.json` 导入（那个只更新名字，不动结构）。

**文档里怎么写图4/图5/视频1**：

```markdown
**上传图**：图1 `林野（男主）.png`｜图2 `主场景.png`｜
图4 `备用人物.png`｜视频1 `动作参考.mp4`
```

解析规则一样：反引号里的文件名，中间用 `｜` 隔开，`图N` 对应第 N 个图槽，`视频N` 对应第 N 个视频槽。
表里只显示前 3 个图槽，**第 4 个往后只在文档里写了才出现**——写了才会多一行。

素材库同时认图片（png/jpg/webp/bmp）和视频（mp4/mov/webm/mkv），视频会复制进 ComfyUI 的 input 目录给参考视频节点用。

### 操作步骤

1. ComfyUI 里把工作流调通，菜单 **「导出 (API)」** 得到 json（**注意不是界面另存那份**，必须是带 `class_type` / `inputs` 的 API 格式）
2. 点顶部 **「工作流映射」** → **「上传工作流 json」**
3. 自动识别后核对 **图1 / 图2 / 图3** 对应节点对不对，不对就在下拉框里改
4. 点 **「保存」**

以后跑片就按这套映射填值。**工作流的连线一律不动**，工具只往指定节点里写值。

### 还需要注意

- 时长单位默认按识别结果，可以在面板里手动改成「秒」或「帧」
- `fps` 只在「帧」单位下用（秒 × fps = 帧数）
- 图槽可以不配（纯文生视频流）；时长也可以不配（用工作流默认时长，合成时按文档时长裁/补黑场）
- 「只跑一采」的二采裁剪逻辑是 MiniMax H3 专属的，节点不存在就自动跳过，不影响别的流

### 其他参数 · 在映射面板里改分辨率这类

工作流映射面板最下面有 **「其他参数」** 区：搜索参数名（中文标题或英文名都行，
比如搜「分辨率」「最长边」「megapixels」），点 **「＋」** 加进来，值可以直接改。
改完点「保存」，之后**每次生成都注入**，不用再去 ComfyUI 里动工作流。

当前这套 H3 工作流最常用的两个：

| 参数 | 节点 | 默认值 | 说明 |
|---|---|---|---|
| `megapixels`（分辨率选择器） | 分辨率选择器（像素） | 0.4 | 成片分辨率（0.4MP ≈ 848×480）。嫌糊可以加到 0.6~0.8，**越大越吃显存** |
| `Number`（最长边尺寸） | 最长边尺寸（分辨率） | 2400 | 参考图喂给模型前的最长边。**OOM 首先降这个**（2400 → 1600 或 1200） |

为什么 8 秒的一采会 OOM：**吃显存的不是视频时长**，是参考图——
这套工作流把每张参考图都缩放到「最长边 2400px」再喂给模型（`ref_image_size=max`），
6 张就是约 19MP 的参考画面；而成片本身只有 0.4MP。视频时长 8 秒还是 20 秒差别不大，
**参考图的数量 × 尺寸才是显存大头**。所以省显存的优先级是：
① 少填几张参考图（没填的槽会自动摘掉，不留模板默认图）→ ② 把「最长边」调小 → ③ 才是降 megapixels。

值里可以写 `{project}` / `{shot}` 占位符（比如文件名前缀类参数），会替换成项目名 / 段号。
换模板后，指向不存在节点的参数会自动清掉，需要重新添加。

## 导出生成好的视频

点顶部 **「导出视频」**：

- 列出所有**已经生成好**的段，默认全勾选
- **「选择文件夹」** 会弹出系统的目录选择框；也可以直接把路径粘进去
- 勾你想导出的段（一段或全部），点 **「开始导出」**
- 文件按段号命名（`G01.mp4`、`G02.mp4`…）复制到你选的目录
- 上次用的目录会记住，下次直接可用

导出是**复制**，不是移动——原始的生成结果还在 ComfyUI 的 `output/doc_director/` 里。

## 生成失败了怎么看

失败的那一行会直接显示红色原因框，**点开看完整说明**（含处理建议）。

常见几种：

| 提示 | 意思 | 怎么办 |
|---|---|---|
| `torch.OutOfMemoryError` | 显存不够 | 少用几张参考图、把分辨率调小（模板里 `ResolutionSelector` 的 megapixels）、时长改短 |
| `被中断了` | 你点了停止，或在 ComfyUI 里把任务取消了 | 重跑就行 |
| `ComfyUI 报错：...` 带节点号 | 那个节点参数不对或缺输入 | 去 ComfyUI 打开同一份工作流看那个节点 |

**参考图会自动瘦身**：某一段只用 2 张图时，工具会把没用到的参考槽从连线上摘掉，
不会让模板里残留的默认图一起参与计算（这是之前显存爆掉的常见原因）。

## 换一集怎么办

把新一集的 `.md` 放进去（格式同上），顶部改文档路径 → **重新解析文档**。
`config.json` 里还可以改 `project_name`（输出子目录名）、`comfy_input_subdir`（input 子目录名）。
不同集的素材放不同文件夹即可。

## 常见问题

**解析出 0 段**：文档标题不是 `### G01 · 00:00-00:12（12 秒）｜...` 这个格式。看上面的格式要求。

**图1 未匹配，生成按钮点了报错**：图1 是必须的（H3 要首帧参考）。手动在下拉框选一张，或者把该段设为跳过。

**生成完找不到 mp4**：看 `output/doc_director/` 下有没有 `G01_1_xxxx.mp4`；没有就去 ComfyUI 控制台看报错。二采关闭时只出 `_1`。

**合成报错**：确认 `ffmpeg` 在 PATH 里（cmd 里敲 `ffmpeg -version` 有输出）。
