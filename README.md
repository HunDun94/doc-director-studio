文档导演台 · 使用说明（2026-11-11 最新版）
============================================================
适用：Windows + 本机运行的 ComfyUI
本版说明与当前程序完全一致，旧说明里的「回收站 / 合成整片」已不存在。


一、这是什么
------------------------------------------------------------
把一份「分段提示词 .md」+ 一个「素材图文件夹」交给本机
ComfyUI，逐段生成图片和视频。

它自己不出画面，负责：
    · 把文档切成段，抓到每段的提示词和该用哪几张图
    · 管理素材库、把图送进 ComfyUI 逐段排队生成
    · 记录每段状态、版本、报错
    · 把生成好的成片导出到你指定的文件夹


二、跑起来的条件
------------------------------------------------------------
1. Python 3.9+（启动脚本会自动找：系统 PATH → py 启动器
   → ComfyUI 整合包的 python_embeded）
2. ComfyUI 已运行，浏览器能打开 http://127.0.0.1:8188
3. ComfyUI 里装着工作流需要的模型和自定义节点
   （名单见 comfyui_latest.json 里各 Loader 节点的 *_name）
4. ffmpeg / ffprobe（需要时按提示装，可放本目录或进 PATH）


三、四步开始
------------------------------------------------------------
1. 启动 ComfyUI
2. 双击「启动文档导演台.bat」，浏览器自动打开
   http://127.0.0.1:8771（黑窗口不要关）
3. 顶部「数据源与 ComfyUI 设置」配三项：
      提示词文档 / 素材图文件夹 / ComfyUI 输出目录
4. 底部日志出现「自检通过」即可开始


四、文档怎么写（五条硬规矩）
------------------------------------------------------------
### G01 · 00:00-00:12（12 秒）｜本段标题

**上传图**：图1 `角色A.png`｜图2 `场景B.png`

**【英文版】**（代码块里是真正发送的提示词）
**【中文版】**（对照用，不发送，界面上可以直接改）

    · 标题必须 ### 开头，段号是 G + 数字
    · 秒必须两位：00:12，不能写 0:12
    · 时长写（12 秒），不能写 12s
    · 「上传图」后面是中文冒号 ：
    · 素材图文件名要和文档里写的完全一致


五、顶栏按钮
------------------------------------------------------------
生成全部        从第一段跑到最后（有筛选时只跑筛选出来的）
只跑未完成      跳过已生成好的段
停止            点了会弹确认（会中断正在跑的 ComfyUI 任务）
导出视频        把生成好的成片移动到你指定的文件夹（见第八节）
重新解析文档    按文档路径重新切段并匹配素材
重新匹配素材    按当前素材库重新匹配所有图槽
导出修改稿      把界面里改过的提示词存成 .md / .txt
删除文档        清空当前文档和全部分段；
                素材图片会移到工具目录的 _trash 文件夹保留（不删除），
                文档文件本身不动，删除前自动备份 shots.json
素材库          管理参考图（见第七节）
折叠图槽 / 全同步  图槽显示开关 / 改一处同步所有段的同名图槽
工作流          查看 / 修改工作流映射（从 ComfyUI 导入、同步节点名、
                自动识别；换模型换工作流用这里）
设置            失败自动重试、按天数隐藏素材成片、全部恢复显示、
                提示词片段、日志下载


六、删除的规则（重要，和旧版不一样）
------------------------------------------------------------
· 删分段：真的从列表删掉（删之前自动存一份备份到 _bak，
  可用「备份恢复」找回）。删掉后重新生成同段号不会报「已存在」。
· 删素材 / 删成片：只是从工具的列表里移除显示，
  文件原封不动留在原地。设置里「全部恢复显示」能放回来。
· 清理残留文件（导出面板里）：把 ComfyUI 落盘的未纳管残留
  移到工具目录的 _trash 文件夹保留，不删除。
· 任何操作都不会销毁你的源文件。


七、素材库
------------------------------------------------------------
· 上传图片 / 改名 / 删除（只移除显示，文件保留）
· 「只看未引用」：筛出没被任何段用到的图
· 列表按最新上传 / 修改排序，最新的在最前面
· 缩略图点击可放大


八、导出视频（注意：是移动，不是复制）
------------------------------------------------------------
1. 点「导出视频」，选择目标文件夹（可粘贴路径）
2. 筛选：段号 / 版本（最新版、旧版）/ 时间 / 文件名搜索
3. 勾选（有全选），点「开始导出」
4. 成片会被【移动】到目标文件夹——ComfyUI 输出目录里
   不再保留原件，段的记录自动指向新位置
5. 「另存为…」：单个成片另存一份（这个是复制，原位置保留）
6. 文件名导出时自动去掉「（新）」标记


九、重跑与找回
------------------------------------------------------------
某段不满意      行尾「生成」重跑，自动编版本号
                G01-1 → G01-2 → G01-3，最新带（新）
删错分段        顶部「备份恢复」从 _bak 找回
                （备份自动只保留最近 5 次）
整份数据坏了    顶部「备份恢复」
误删的素材/成片 设置 → 「全部恢复显示」


十、出问题
------------------------------------------------------------
先看「常见问题与处理.txt」按现象查。
排查时备好三样：
    1. 页面底部运行日志最后 5 行
    2. 出错段行尾的红字（点开是完整报错）
    3. ComfyUI 黑窗口里对应的报错
服务断了页面顶部会显示「⚠ 服务已断开」，
关掉黑窗口或双击 bat 重新启动即可。
