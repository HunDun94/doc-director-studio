文档导演台 · 常见问题与处理
============================================================
按现象查。写法都是「现象 → 原因 → 怎么办」。


【一、打不开 / 连不上】
------------------------------------------------------------
1. 浏览器打不开 127.0.0.1:8771
   → 服务没启动，或黑窗口被关掉了
   → 双击「启动文档导演台.bat」，黑窗口别关

2. 黑窗口一闪就没了
   → 没有 Python，或没加进 PATH
   → 装 Python 3.9+ 并勾选 Add to PATH；或确认用的是 ComfyUI 整合包自带的 python

3. 提示端口被占用
   → 已经有一个导演台在跑
   → 任务管理器结束多余的 python 进程，或直接用已经打开的页面

4. 页面打得开，但顶部显示「ComfyUI 离线」
   → ComfyUI 没启动，或端口不是 8188
   → 先启动 ComfyUI；换端口就在设置里改「ComfyUI 地址」

5. 换电脑后浏览器打不开
   → 可能被防火墙拦了
   → 允许 Python 通过防火墙，或直接把 http://127.0.0.1:8771 粘进浏览器


【二、文档解析】
------------------------------------------------------------
6. 解析出 0 段
   → 标题行格式不对
   → 必须是：### G01 · 00:00-00:12（12 秒）｜标题
   → 重点看：三个井号、秒两位（00:12 不是 0:12）、时长写（12 秒）不是 12s

7. 段数比文档里少
   → 段内出现了 ## 两级标题，把当前段的收集掐断了
   → 段内不要用 ##，只有 ### 才是段标题

8. 某几段自动被标成「已跳过」
   → 图槽全空
   → 检查「上传图」后面是不是中文冒号 ：（半角 : 会导致整行失效）
   → 纯黑场/纯字幕段本来就是无图，跳过是对的

9. 图槽标红 ⚠ 未匹配
   → 素材库里没有同名文件（不做模糊匹配）
   → 在下拉里手动选一张，或把素材图改成和文档一致的名字
   → 批量改完名字后点「重新匹配素材」

10. 新增的段没有图，能不能生成
    → 新增时勾「不用参考图」，提交时会把参考图连线和 LoadImage 节点全部摘掉
    → 但「参考图生视频」类节点（如 ReferenceToVideo）通常要求至少 1 张图，
      这种工作流勾了也可能报错，报什么看 ComfyUI 黑窗口
    → 纯文生视频的工作流（映射里本来就没有图槽）则完全不需要图

11. 新增段的段号怎么算
    → 取当前「没被删除」的段里最大的那个 +1
    → 删掉若干段后，按剩下的最大值递增（最新是 G14 → 新段 G15）
    → 想用别的号直接在弹窗里改

12. 新增的段导出后没有名字
    → 段号要符合「字母 + 数字」（如 G23），否则成片文件名匹配不上
    → 标题随便写，成片列表里用的就是这个标题

13. 段号写错了想改
    → 点段号右边的 ✎
    → 已经生成过视频的段不能改（文件名会对不上），先删掉成片再改

14. 段号不是 G01 这种
    → 当前解析器只认 G + 数字
    → 把文档段号改成 G01、G02；换文档后筛选里的段号会自动跟着变


【三、生成失败】
------------------------------------------------------------
15. 报 OutOfMemory / 显存不足
    → 按顺序降级，别反着来：
       ① 少填参考图
       ② 参考图最长边调小（如 2400 → 1600）
       ③ 最后才降 megapixels（1.0 → 0.8 → 0.6）
    → 同时把虚拟内存调大（大文本编码器很吃内存）

16. 报「找不到模型」/ Value not in list
    → 工作流模板里写死的模型名，在对方 ComfyUI 里不存在
    → ComfyUI 调通 → 导出 (API) → 「工作流映射」上传 → 保存
    → 也可以点「从 ComfyUI 导入」直接抓最近一次运行的完整工作流

17. 报节点缺失 / 画布标红
    → 缺自定义节点
    → 在 ComfyUI-Manager 里按节点名安装，重启 ComfyUI

18. 一直排队没动静
    → ComfyUI 队列里还有别的任务
    → 页面会显示「队列里还排着 N 个」，等它跑完或去 ComfyUI 清队列

19. 跑到一半停了
    → 点了「停止」（当前段跑完才停），或 ComfyUI 崩了
    → 点「只跑未完成」续跑，已完成的不会重跑

20. 某段反复失败，其它正常
    → 通常是这段的图或提示词有问题
    → 点开红字看完整报错；试着把该段图槽减到 2 张


【四、画面不对】
------------------------------------------------------------
21. 成片发糊
    → 分辨率偏低
    → 提高工作流里的 megapixels（或分辨率节点）；
      0.4 → 864×480，0.8 → 约 1184×672，1.0 → 1312×736
    → 参考图最长边也别压得太小
    → turbo / 少步数 LoRA 本身偏软，属正常

22. 合成后尺寸忽大忽小、有黑边
    → 合成以第一段输出的分辨率统一全片
    → 重跑那些低分辨率旧段，或先清掉它们的旧输出

23. 人物/场景不像素材
    → 参考图太少或分辨率太低
    → 填满关键角色与场景的图槽；提示词里明确指代（如 <Picture 1>）

24. 中文提示词能用吗
    → 能。每段可选「正面提示词：英文版 / 中文版」
    → 若用的是英文训练的 LoRA，英文命中率通常更稳
    → 想试就同一段跑两版对比


【五、合成与导出】
------------------------------------------------------------
25. 合成失败 / 提示 ffmpeg
    → 没装 ffmpeg，或不在 PATH
    → 把 ffmpeg.exe 和 ffprobe.exe 复制到工具目录（优先用它）

26. 合成出来某几段是黑屏
    → 那些段还没生成，程序自动补黑场
    → 生成完再合成一次

27. 导出的文件名和界面不一样
    → 正常。界面带（新），导出会去掉；版本号 G01-2 保留

28. 导出把旧文件覆盖了
    → 同名会覆盖
    → 想留两版就分两个文件夹，或用「另存为…」

29. 删掉的成片不见了
    → 进了回收站
    → 导出面板 →「回收站」→ 还原；「彻底删除」才真删


【六、数据与备份】
------------------------------------------------------------
30. 不小心点了「删除上传文档」
    → 分段被清空，但清空前自动备份了
    → 顶部「备份恢复」→ 选 shots.cleared-时间.json → 恢复

31. 改了很多提示词想留底
    → 「导出修改稿」，选 .md 或 .txt

32. 想做新一集
    → 先「导出修改稿」存档，再「删除上传文档」，然后选新文档
    → shots.json 只存当前这一集

33. 备份越来越多
    → 每个快照几百 KB，一般不用管
    → 要清理就手动删旧的 shots.*.json（别删 _bak 目录）

34. .txt 打开乱码
    → 已写成带 BOM 的 UTF-8，不该乱码
    → 若用别的编辑器，把编码手动选成 UTF-8


【七、分享给别人时】
------------------------------------------------------------
35. 对方跑起来报「找不到模型」
    → 他的模型文件名和你不一样
    → 让他在自己 ComfyUI 里调通后导出 API 工作流，再从「工作流映射」上传

36. 对方看不到你的分段
    → 正常，shots.json 是你这一集的数据，分享时不要带
    → 他需要自己的 .md；或你「导出修改稿」把 .md 给他

37. 对方没有 Python / ffmpeg
    → 装 Python 3.9+（勾 Add to PATH）
    → ffmpeg.exe、ffprobe.exe 直接丢进工具目录，不用配环境变量


【八、界面小事】
------------------------------------------------------------
38. 点「选择文件…」没反应
    → 系统对话框被拦或弹到后台
    → 直接把路径粘进输入框，效果一样

39. 页面每 2.5 秒刷新一次
    → 正常的自动刷新；正在输入时不会打断

40. 按钮找不到
    → 顶部三段：左=跑片，中=文档操作，右=查看与设置
    → 「筛选 ▾」里还有搜索

41. 想看整张表
    → 折叠条右侧的 ⛶ 全屏


【九、新功能相关】
------------------------------------------------------------
42. 生成过程中改提示词，还会按旧的跑吗
    → 不会。每段开始前都会重新读一次数据，改完从下一段起生效

43. 提示「预检未通过，已跳过」是什么意思
    → 批量生成前的本地检查：提示词为空 / 时长不对 / 图1 没选
    → 按提示补齐即可；确实不用图的段，勾「不用参考图」

44. 素材或成片突然不见了
    → 可能被「设置 → 自动隐藏」隐藏了
    → 设置里点「全部恢复显示」，文件一直都在

45. 导出点了没反应
    → 现在导出是后台任务，面板上会出现进度条
    → 如果进度条不动，看日志里有没有「导出失败」

46. 日志想看全部
    → 页面上只显示最近 500 行
    → 设置 →「查看完整日志」或「下载本次日志」

【十、还是不行】
------------------------------------------------------------
把这三样发出来，基本能定位：
    1. 页面底部运行日志最后 5 行
    2. 出错那段行尾的红字（点开是完整报错）
    3. ComfyUI 黑窗口里对应的报错行
